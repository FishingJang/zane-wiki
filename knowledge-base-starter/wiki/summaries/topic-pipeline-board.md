# Topic Pipeline Board

## 目的
这页不是 topic index，而是一个轻量状态面板。
它用来回答：
- 哪些主题已经形成活跃主线
- 哪些主题只是孵化中的候选方向
- 哪些材料已经入库但暂时不该推进

## 状态定义
- `inbox`：刚进入系统，尚未分流
- `routed`：已完成 articles / books / notes / cases 等路径分流
- `seeded`：已形成候选主题、摘要页或入口页
- `compiled`：已进入 wiki，并纳入导航/索引
- `parked`：已判断暂不推进，但保留在库中
- `archived`：长期冻结，仅保留检索与追溯能力

## starter 默认用法
在一个刚初始化的知识库里，这页一开始可以很空。
它真正开始有价值，通常发生在第二阶段：
- 已有第一批 raw
- 已出现混合目录或多类型输入
- 已开始出现“哪些该升 seed、哪些先停”的判断需求

## 推荐维护方式
- 先按主题线或批次维护，不追求逐文件状态管理
- 至少区分三类：active / incubating / routed-but-not-promoted
- 有真实判断案例后，再逐步丰富
