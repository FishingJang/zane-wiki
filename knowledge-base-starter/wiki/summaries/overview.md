# Project Overview

## 项目定位
这是一个新初始化的知识库入口页。

它不是“所有材料直接进 wiki”的图书馆，而是一个分层知识系统：
- `raw/` 负责低成本收纳、分流、保留原始语义
- `wiki/` 负责主题化编译、概念抽取、导航组织
- `outputs/` 负责面向任务的报告、回答与方案产物

## 当前状态
- 这里还没有正式编译出的 topic / concept / case
- 应先把第一批 raw 资料完成路由，再开始形成 wiki
- 进入第二阶段后，可补 lifecycle 面板、升级判断清单与重复材料治理规则
- 当 starter 已开始实际跑 cycle 时，`outputs/reports/` 不再只是附件目录，而是运行状态的重要入口
